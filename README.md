## 1. Project Overview

The Restaurant Menu Manager is a mobile application developed using React Native and Expo for a restaurant owner named Christoffel.

The purpose of the application is to simplify the management of restaurant menu items. Previously, menu information was managed manually on paper, making it difficult to add dishes, update information, organise menu items and find specific dishes quickly.

This application provides a digital solution that allows the restaurant owner or chef to manage menu items using an Android mobile device.

## 2. Part 1 – Planning and Design

Part 1 focused on analysing the scenario, identifying the application requirements and planning the user interface before development.

The planning and design activities included:

- Analysing the restaurant's menu-management challenges.
- Identifying the functional requirements of the application.
- Planning the application's user interface.
- Creating wireframes for the main application screens.
- Designing the application flow.
- Identifying the React Native components required for development.
- Preparing a design reflection.

### Planned Application Screens

The application design included the following screens:

1. **Home Screen:** Provides an overview of the application and menu statistics.
2. **Menu Screen:** Displays menu items and provides search and filtering functionality.
3. **Add Menu Screen:** Allows users to add new dishes.
4. **Edit Menu Screen:** Allows users to update existing menu items.

The application flow diagram illustrates how users navigate between the different screens and interact with the application.

## 3. Part 2 – Application Development

Part 2 focused on developing the first working version of the Restaurant Menu Manager using React Native and Expo.

The initial application provided the basic functionality needed to manage restaurant menu items.

### Features Implemented

- Adding new menu items.
- Displaying menu items.
- Capturing dish information.
- Selecting a course for each dish.
- Basic form validation.
- Displaying menu item information.

### Menu Item Information

Each menu item includes:

| Field | Description |
|---|---|
| Dish Name | Name of the restaurant dish |
| Description | Details about the dish |
| Course | Starter, Main Course or Dessert |
| Price | Price of the dish |

Part 2 established the foundation for the additional features introduced in Part 3.

## 4. Part 3 – Application Enhancements

Part 3 focused on improving the existing application by adding more functionality and improving the overall user experience.

### 4.1 Menu Management

Users can:

- Add new menu items.
- View existing menu items.
- Edit and update menu items.
- Delete menu items.
- Confirm deletion before removing a dish.

### 4.2 Search and Filtering

The application includes:

- Search functionality to find menu items by dish name.
- Filtering by course.
- Options to clear the search and filters.

### 4.3 Menu Statistics

The application provides useful menu statistics, including:

- Total number of menu items.
- Average menu item price.
- Number of Starters.
- Number of Main Courses.
- Number of Desserts.

These statistics help the restaurant owner understand and organise the restaurant menu.

### 4.4 User Experience Improvements

Several improvements were made to make the application easier to use:

- Improved screen layout and organisation.
- Clear navigation and user interactions.
- Form validation to prevent incomplete entries.
- Success and error messages.
- Improved menu item management.
- Clearer buttons and input fields.
- Confirmation before deleting menu items.

## 7. Running the Application

To run the application locally, follow these steps:

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Navigate to the project folder**

```bash
cd RestaurantMenuManager
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start Expo**

```bash
npx expo start
```

**Step 5: Run the application**

Press `a` in the Expo terminal to open the application in an Android emulator.
